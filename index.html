راه‌اندازی هوش مصنوعی محلی

MANIX از Ollama استفاده می‌کند. Ollama موتور اجرای مدل است؛ مدل روی دستگاه خودت اجرا می‌شود و نیازی به کلید API یا حساب سرویس هوش مصنوعی نداری.

وضعیت اتصال هنوز بررسی نشده است.

نصب یک‌باره

۱) Ollama را از سایت رسمی ollama.com برای Windows، macOS یا Linux نصب کن.
۲) ترمینال را باز کن و مدل را دریافت کن:
ollama pull qwen2.5-coder:7b
۳) در پوشه‌ای که سه فایل MANIX هستند، سرور را اجرا کن:
python -m pip install -r requirements.txt
python server.py
۴) مرورگر را در آدرس http://127.0.0.1:8000 باز کن.

مدل 7B به حافظه کافی نیاز دارد. اگر سیستم ضعیف است، مدل کوچک‌تر نصب کن و نام آن را در تنظیمات بنویس. خود مدل جدا از این سه فایل دانلود می‌شود.
